# 本機快速啟動

## 第一步：複製專案
```bash
git clone https://github.com/Gus0418/-.git
cd -/claude-project
```

## 第二步：安裝所有依賴
```bash
npm install
```

## 第三步：設定 API Keys
```bash
cp .env.example .env
```
用任意文字編輯器開啟 `.env`，填入您的 API Key：
```
ANTHROPIC_API_KEY=sk-ant-api03-xxxxx   ← 必填
OPENAI_API_KEY=sk-xxxxx                ← 選填
GOOGLE_GENERATIVE_AI_API_KEY=xxxxx     ← 選填
GROQ_API_KEY=xxxxx                     ← 選填
```
> 只有 `ANTHROPIC_API_KEY` 是必填，其他選填（沒填的模型競賽時會顯示失敗）

## 第四步：啟動介面
```bash
# 全功能介面（20種主題）
node web-full.mjs

# 或用 npm 指令（需要 dotenv-cli）
npm run web:full
```

## 第五步：開啟瀏覽器
```
http://localhost:3000
```

---

## 常見問題

**Q: `node: command not found`**
→ 請先安裝 Node.js 18+：https://nodejs.org

**Q: `Cannot find package '@anthropic-ai/sdk'`**
→ 執行 `npm install` 再重試

**Q: `Error: please set ANTHROPIC_API_KEY`**
→ 確認 `.env` 檔案存在且 API Key 已填入

**Q: 只想快速試用，不想設定**
→ 直接執行 `node web-full.mjs`（無 API Key 時，對話功能會報錯，但介面和主題切換正常）
